## ЭТАП 1 — Доверие к цифрам (1-2 сессии)
*Цель: на любом экране цифры сходятся между собой и объяснимы.*

### 1.1. Рассинхрон 313 286 vs 54 792 на дашборде директора
- [ ] **Суть:** блок «Реальные данные МДЛП» берёт данные с сервера (все 313K строк), а KPI-карточки — из клиентского `SALES_DATA`, который строится из компакт-выборки 15 000 строк. Два числа на одном экране противоречат.
- **Файлы:** [SharedDataContext.tsx](../src/context/SharedDataContext.tsx) (`reloadFromServer` — лимит 15000 в ответе `/api/yearly-data/:userId/9999`), [server/index.ts](../server/index.ts) (compact rows отдаются целиком или режутся), [DirectorWMDashboard.tsx](../src/app/components/wm-russia/dashboards/DirectorWMDashboard.tsx).
- **Как чинить:** выяснить где режется выборка (15000 = COMPACT_CHUNK_SIZE? лимит в query?). Вариант А — отдавать клиенту агрегат по (регион×препарат×месяц) вместо сырых строк: размер упадёт на порядки, цифры совпадут. Вариант Б — грузить все чанки.
- **Проверка:** KPI «Продажи 2026» на дашборде директора == «Упаковок продано» в блоке МДЛП.

### 1.2. «Выполнение плана 54792%» — подпись и потолок
- [ ] **Суть:** план из regional_plans честный, но пока РМ ввёл 100 тестовых упаковок — процент абсурден и пугает.
- **Файлы:** [DirectorWMDashboard.tsx](../src/app/components/wm-russia/dashboards/DirectorWMDashboard.tsx) (kpiCards, planExecution).
- **Как чинить:** подпись под карточкой «План: N упак. (заполнили M РМ)»; если процент > 500% — показывать «план занижен» вместо числа.
- **Проверка:** карточка с тест-планом 100 упак. читабельна и не вводит в заблуждение.

### 1.3. Заполнить drug_prices реальным прайсом
- [ ] **Суть:** таблица пуста → вся выручка по каталожным ценам (оценки). Все рубли на сайте условные.
- **Действие пользователя:** внести реальный прайс-лист через админку (Препараты → цены) или дать файл — я загружу скриптом в drug_prices.
- **Проверка:** лог `[SharedData] Обновлено из БД: N строк, 12 цен` (не «0 цен»).

### 1.4. percapita: рубли = упаковкам при первом заходе
- [ ] **Суть:** эндпоинты /percapita и /peremployee не возвращают drugSales → `calcRublesRatio` = 1 → «1 500 уп. | 1 500 ₽».
- **Файлы:** [server/tabDataRoutes.ts](../server/tabDataRoutes.ts) (~2621-2630 — ответы percapita/peremployee), [src/app/App.tsx](../src/app/App.tsx) (rublesRatio).
- **Как чинить:** добавить drugSales (уже посчитан в filtered) в ответы обоих эндпоинтов.
- **Проверка:** зайти на «Аналитика эффективности» ПЕРВОЙ вкладкой после логина — рубли ≠ упаковкам.

### 1.5. Сохранённый отчёт МДЛП теряет фильтры
- [ ] **Суть:** saveCurrentReport хранит только drug/year/period; регионы/менеджеры/ФО/типы выбытия теряются → отчёт из архива показывает другие цифры.
- **Файлы:** [src/app/App.tsx](../src/app/App.tsx) — saveCurrentReport (~1186), loadReport (~1214), preview архива (~1628), экспорт (~1246).
- **Как чинить:** сохранять в report.filters полный набор + восстанавливать в loadReport + передавать в fetchTabData при preview/export.
- **Проверка:** сохранить отчёт с фильтром по региону → открыть из архива → те же цифры.

### 1.6. AI-кнопка «Прогноз» МДЛП мертва после F5
- [ ] **Суть:** `if (!uploadedData) return` — uploadedData есть только при клиентском парсинге; после перезагрузки кнопка активна, но молчит.
- **Файлы:** [src/app/App.tsx](../src/app/App.tsx) (~6611 generate-comment).
- **Как чинить:** передавать в api.analytics.generateComment серверные агрегаты (tabData.drugSales/monthlySales) вместо uploadedData.
- **Проверка:** F5 → Прогноз → «Сгенерировать комментарий» → спиннер и текст.

### 1.7. Фильтр менеджера без регионов показывает всё
- [ ] **Суть:** пустой mgrRegions → параметр не отправляется → фильтр молча игнорируется.
- **Файлы:** [src/app/App.tsx](../src/app/App.tsx) (~630 params.managerRegions).
- **Как чинить:** при выбранном менеджере с пустыми регионами слать `managerRegions=['__none__']` → сервер вернёт пусто; в UI бейдж «у менеджера не заданы территории».
- **Проверка:** выбрать менеджера без регионов → нулевые данные + подсказка.

## ЭТАП 2 — Надёжность (1-2 сессии)
*Цель: сайт не падает и не теряет данные в предсказуемых сценариях.*

### 2.1. Таймаут холодной загрузки compact rows (поймано live: 226 сек)
- [ ] **Суть:** первый запрос с фильтром месяцев после рестарта сервера грузит 313K строк из jsonb и может упереться в statement_timeout (120s). После прогрева кэша — 2 мс.
- **Файлы:** [server/tabDataRoutes.ts](../server/tabDataRoutes.ts) (loadCompactRowsIfNeeded), [server/db.ts](../server/db.ts) (таймауты).
- **Как чинить:** (а) прогрев: после login/старта сервера фоном загрузить compact rows активных юзеров в кэш; (б) для этого запроса использовать heavy-клиент (600s) вместо обычного; (в) стратегически — хранить compact rows не одним jsonb, а строками таблицы с индексами.
- **Проверка:** рестарт сервера → сразу фильтр месяцев → ответ < 30 сек без ошибки.

### 2.2. Мониторинг прода (/api/health + внешний пинг)
- [ ] **Суть:** если cron GRANT'ов Timeweb умрёт — сайт ляжет молча через ~10 дней.
- **Как чинить:** эндпоинт `/api/health` (SELECT 1 + счётчик users) без авторизации; внешний uptime-пинг (UptimeRobot free / cron с другого хоста) на него с алертом на email; в шапке админки бейдж состояния БД.
- **Проверка:** остановить PG-доступ → алерт приходит.

### 2.3. Отчёт о несматченных строках после загрузки
- [ ] **Суть:** регион/препарат, не совпавший с каталогом побуквенно, молча даёт нули.
- **Файлы:** [server/fileProcessor.ts]/место агрегации, [SharedDataContext.tsx](../src/context/SharedDataContext.tsx) (getWmProductKey), экран Загрузки.
- **Как чинить:** при обработке файла считать нераспознанные значения (drug/region) → вернуть в статусе загрузки → показать плашку «⚠️ 213 строк не сопоставлены: [Тизины 5мг…], [Респ. Татарстан…]» с кнопкой «показать список». Плюс нормализация: trim, ё→е, регистронезависимо, «Респ.»↔«Республика».
- **Проверка:** загрузить файл с опечаткой в регионе → увидеть предупреждение, а не тихие нули.

### 2.4. Refresh-токены
- [ ] **Суть:** JWT 24ч; interceptor выбрасывает на логин, но несохранённый ввод (план РМ, сценарий) теряется.
- **Файлы:** [server/index.ts](../server/index.ts) (auth), [src/lib/api.ts](../src/lib/api.ts).
- **Как чинить:** пара access (1ч) + refresh (30д, httpOnly cookie или отдельный стор), тихое обновление в fetchApi при 401 → повтор запроса; logout инвалидирует refresh.
- **Проверка:** оставить вкладку на сутки → продолжить работу без разлогина.

### 2.5. Dev-база отдельно от прода
- [ ] **Суть:** локальная разработка ходит в боевую analizator2 — эксперименты видны юзерам.
- **Как чинить:** вторая БД на том же Timeweb (analizator_dev) или локальный Postgres в Docker; `.env.development` с другими кредами; сид демо-данных (маленький файл выгрузки).
- **Проверка:** npm run dev пишет в dev-базу; прод не видит тестовых записей.

### 2.6. managerRegions enforcement (миграция)
- [ ] **Суть:** роль manager видит все данные своей загрузки; закрепление регионов за РМ не форсируется сервером.
- **Как чинить:** колонка `users.regions text[]` (или таблица user_regions); при роли manager сервер добавляет фильтр по ним во все /api/tab/*; UI админки для назначения.
- **Проверка:** РМ с 3 регионами видит только их даже без фильтров.

### 2.7. Гигиена (фоновые, по ходу других задач)
- [ ] Money в копейках (integer) вместо NUMERIC/float в новых расчётах.
- [ ] strictNullChecks инкрементально (сейчас 228 ошибок).
- [ ] Убрать `any` в местах, которые трогаем (273).
- [ ] Стабильные React keys вместо index (75 мест).

## ЭТАП 3 — Усиление аналитики (по волнам, каждая волна — отдельная фича)

### Волна А — быстрые победы (данные уже в БД)

#### А1. Сравнение двух загрузок (killer-фича)
- [ ] **Данные есть:** upload_history (все загрузки, is_active), yearly_sales_data по годам.
- **Что дописать:** серверный эндпоинт `/api/tab/compare-uploads?a=uploadId1&b=uploadId2` — агрегаты обеих выборок; экран «Дельта»: таблица регион/препарат/контрагент с колонками «Было / Стало / Δ / Δ%», сортировка по |Δ|, топ-роста и топ-падения.
- **Ценность/сложность:** ★★★★★ / средняя.

#### А2. Отток контрагентов (churn)
- [ ] **Данные есть:** contragentRows с месяцами (1 147 уникальных контрагентов).
- **Что дописать:** вкладка в «Контрагенты»: список «закупали в месяце M-1, нет в M» + «новые в M», с регионом и объёмом прошлых закупок. Это готовый список обзвона для МП.
- **Ценность/сложность:** ★★★★★ / низкая.

#### А3. ABC×XYZ матрица
- [ ] **Данные есть:** помесячные продажи по препаратам.
- **Что дописать:** XYZ = коэффициент вариации месячных продаж (X<10%, Y10-25%, Z>25%); матрица 3×3 в существующей вкладке ABC.
- **Ценность/сложность:** ★★★★ / низкая.

#### А4. Декомпозиция роста (объём × цена × микс)
- [ ] **Данные есть:** quantity и amount в каждой строке.
- **Что дописать:** на «Сравнении периодов»: Δвыручки = Δобъёма + Δцены + Δмикса (стандартный price-volume-mix). Отвечает «мы продаём больше или дороже?».
- **Ценность/сложность:** ★★★★ / средняя.
